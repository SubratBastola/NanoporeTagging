📦 Export data and configuration

One .tar file with everything people made on this server, for moving NanoTag to another machine: user accounts (with their passwords), experiments, recordings, annotation sets, events and their edit history, NN models, clustering runs and outputs, and the server settings.

Working out sizes …

On the new server (after deploy/install.sh), import it with sudo ./deploy/migrate-from.sh nanotag-site-….tar, or let the script fetch everything itself straight from this server over SSH (resumable; best for ABFs):

sudo ./deploy/migrate-from.sh you@{{ request.host.split(':')[0] }} --with-abf

The import replaces the new server's (empty) data, keeps its own secret key and port, and backs up whatever database it had. Command line here: sudo nanotag-admin export-site --with-zarr.
