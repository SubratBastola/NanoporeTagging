Import a folder of ABFs + event CSVs📂 Import folder → type or browse to the folder → Scan → check the plan (files with an _event.csv are ticked; baseline runs are not) → Import. DC / AC / AOM runs of one sample go into one experiment; ABFs already on the server are used in place.
Delete an experimentExperiments → tick it → 🗑 Delete selected… (or 🗑 on its row, or its sidebar). You see what will be removed first. Admins and the experiment’s creator can delete.
